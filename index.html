Export your results from R

Run this after calculating rankings, then import rankings.json above. Imported results stay in this browser only. The published page loads the shared R export automatically. Manual imports temporarily override it in your browser; Load shared results restores the published dataset.

install.packages("jsonlite") # Once only
jsonlite::write_json(
  list(
    updated_at = format(Sys.time(), "%Y-%m-%dT%H:%M:%SZ", tz = "UTC"),
    rankings = rankings
  ),
  "rankings.json",
  dataframe = "rows",
  auto_unbox = TRUE,
  pretty = TRUE,
  na = "null"
)

Rating is the average of each game's ratio; it is not PPG divided by average turnovers. Zero turnovers use a denominator of 1. Missing box scores are excluded. Division I filtering remains provisional. This is a test metric, not an opponent-adjusted strength rating.
